# ZOOX — The Legacy of Fine Taste 🍽️✨

A premier luxury fine dining restaurant website for **ZOOX** (A Unit of The Grand Portico), located on Tarapith - Dumka Road, Rampur, Dumka, Jharkhand.

## 🌟 Highlights
- **Multi-Page Luxury Architecture**:
  - `index.html` — Immersive full-bleed hero, stats strip, signature dishes, ambiance previews, 3-column verified Google reviews grid, and interactive map.
  - `experience.html` — The ZOOX dining story, private glass cabins highlight, and luxury amenities.
  - `menu.html` — Interactive categorized dynamic menu (Tandoor E Dastaan, Indian Main Course, Asian Appetizers, Continental Appetizers, Continental Main Course, Chinese Rice & Noodles, Salads & Soups, Desserts).
  - `gallery.html` — Masonry photography showcase with hover reveal captions.
  - `reservation.html` — Table booking system with automatic WhatsApp message integration.
- **Design System**: Rich dark emerald/ink (`#111a15`), warm cream (`#f7f4ed`), antique gold (`#c89d58`), and refined typography (`Playfair Display`, `DM Sans`, `DM Mono`).
- **Interactive UI**: Scroll-reveal animations, gold shimmer buttons, draggable tabs, back-to-top button, and mobile-friendly responsive navigation.
